Build date: 2026-11-11. Approved spec: [spec.md](spec.md). Local integration branch: `codex/omp-work-manager`, based on `2543722e2d8ee319505b9759eef8300b12879e23`.

## Scope

The opt-in OMP extension exposes a durable local queue, explicit branch worktrees, dependency scheduling, a shared model-worker limit, actual validation, independent Spec and Standards review, bounded repair, feature integration, recovery, safe cleanup, and current upstream skills. Concrete model choices remain local and resolve from the live OMP catalog at dispatch. No production package dependencies were added.

The original checkout's unrelated modifications were preserved. Nothing was pushed, published, deployed, or installed into the user's active OMP profile. Company artifacts, credentials, and models were not used.

## Review-driven regressions

- Cleanup retains ignored local data instead of letting Git remove it with the worktree.
- A detached validation process is journaled before its command can execute. After a host crash, resume blocks while its group survives, reconciles a confirmed drained group, and verifies the existing committed candidate without duplicate implementation.
- An expired review waiting for a shared worker slot never dispatches after that slot becomes free.
- Each role resolves the live model choice after acquiring its slot; review evidence records the actual selected identity.
- The main session receives an immutable skill inventory, exact resource paths, and OMP invocation guidance through the skills interface.
- Completed checks from an earlier branch stage remain historical evidence when the same ticket is checked in its integration worktree; unresolved processes still prevent readiness.

## Limits and work-laptop acceptance

Execution continues while the managing OMP process is alive. There is no background operating-system service, cross-laptop queue, model ranking, automatic publication, or security sandbox. Checks must be repeatable; an interrupted check with unknown identity requires explicit reconciliation. Cleanup preserves unaccounted ignored files, including caches or local data, until they are inspected and explicitly removed.

Run an approved small task locally on the work laptop before adopting the manager for daily work. Verify its OMP version, provider/proxy, permissions, checks, current skills, and chosen models there. Keep tasks, source, transcripts, receipts, and model assignments on that laptop. A permitted manual behavior description can guide a synthetic reproduction here without transferring work artifacts.

Passing tests and independent agent reviews improve confidence; they do not prove that every defect or poor model assessment will be found.
